# Life Operating System (LOS)

Markdown-native life management powered by [Claude Code](https://claude.ai/code).

**[View the full guide →](https://gadofir.github.io/LOS-starter/)**

## Quick Start

```bash
git clone https://github.com/GadOfir/LOS-starter.git
cd LOS-starter && claude
```

Then say: `"start session"`, `"learn docker"`, `"new project my-app"`, or `"review"`.

## Part of the Kingdom of God

LOS is the optional **memory layer** for the [Kingdom of God](https://gadofir.github.io/kingdom-of-god/) — a persona-matrix skill router (God → King → Workers). The King reads LOS for long-term context across sessions and projects; Agent Retro writes learnings back. The kingdom works without it, and remembers with it.
