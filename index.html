How it works

Three steps. Nothing to install beyond Claude Code.

Clone and open

Clone this repo. Run claude in the directory. Claude reads CLAUDE.md and loads all skills automatically.

Talk naturally

Say "learn Docker networking" or "new project my-saas". Claude routes to the right skill based on what you said.

Everything stays in markdown

Knowledge, projects, tasks, decisions, logs — all plain markdown files. Version controlled. Portable. Yours.

Design principles

The ideas behind the system.

One file = one truth

Tasks, knowledge, projects each live in a single file. Nothing scattered across docs.

Skills, not commands

Skills 2.0 format with frontmatter, discovery, and argument hints. No legacy wrappers.

Self-healing

/evolve detects broken indexes, missing files, and stale knowledge. Fixes what it can, flags the rest.

Cross-project

Drop .claude.los into any repo. Claude logs actions back to your central LOS and pulls context when needed.

Plain markdown

No database, no app, no sync service. Git-versioned text files you own completely.

Grows with you

/create-skill builds new skills on demand. The system extends itself.
